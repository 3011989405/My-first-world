清除浮动
场景：浮动元素会脱标，如果父级没有高度，子级无法撑开父级高度（可能导致页面布局错乱）
解决办法：清除浮动（清除浮动带来的影响）

清除浮动方法：
1.额外标签法：在父级元素内容的最后添加一个块级元素，设置CSS属性clear: both;
2.单伪元素法：.clearfix::after{
	content: "";
	display: block;
	clear: both;
}
3.双伪元素法（推荐）：.clearfix::before,
        .clearfix::after{
            content: "";
            display: table;
        }
        /* after:清除浮动影响 */
        .clearfix::after{
            clear: both;
        }
4.overflow：父级元素添加CSS属性overflow: hidden;
