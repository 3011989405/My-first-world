记忆口诀

1️⃣ 标签 = 英文单词

p = paragraph、img = image、a = anchor、tr = table row、ul = unordered list

2️⃣ CSS 前缀定类别

font-管字长相、text-管排版、background-管背景、border-管边框

3️⃣ padding 内、margin 外

padding 是自己家加垫子（盒子变大）；margin 是和邻居保持距离

4️⃣ 顺时针简写

上右下左，永远这个顺序：padding: 10px 20px = 上下10 左右20

5️⃣ margin: 0 auto = 水平居中

最常用的居中方式，记住这一个赢一半

6️⃣ 记不住时怎么办

VS Code 里鼠标悬停标签有英文解释；用本页搜索框随时查

3 分钟复习法

① 随机打开一个你写过的 .html 文件　② 看每个标签，在心里说出它的英文单词（p → paragraph）　③ 看每个 CSS 属性说出它管什么　④ 说不出来的，用本页搜索框查并记下来 ✅

记忆的真相：不是"背会"，而是"每次查完都能想起"。查 7 次以上就成肌肉记忆了。
